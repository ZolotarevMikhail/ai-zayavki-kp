# Заявка → КП

Система для малых производств: заявки клиентов (текст, PDF, Excel, Word, фото)
система распознаёт через нейросеть, сотрудник проверяет данные на простом
экране, стоимость считается по формулам компании, и в один клик собирается
готовое коммерческое предложение в Word.

Два канала приёма заявок: загрузка файла на странице и вложения с электронной
почты. ИИ отвечает только за распознавание; все деньги считает обычный код по
прайсу компании, поэтому итоговые цифры всегда точные.

## Как запустить (для не-программиста)

1. Открыть терминал в папке проекта.
2. Один раз подготовить окружение и зависимости:

   ```bash
   python3 -m venv venv
   venv/bin/pip install -r requirements.txt
   ```

3. Запустить систему:

   ```bash
   venv/bin/python app.py
   ```

4. Открыть в браузере http://127.0.0.1:5000

Режимы работы:

- **Демо (по умолчанию):** распознавание работает на встроенном примере,
  ИИ не вызывается, расходов нет. Для прогона загрузите файл
  `demo/sample_zayavka.txt`.
- **Реальный:** скопируйте `.env.example` в `.env`, впишите ключ ProxyAPI
  (`PROXYAPI_KEY`) — распознавание любых документов и картинок заработает.
- **Почта:** в `.env` заполните `IMAP_HOST`, `IMAP_USER`, `IMAP_PASSWORD` —
  появится кнопка «Проверить почту».
- **Telegram и VK:** в `.env` заполните `TELEGRAM_BOT_TOKEN` (из @BotFather)
  и `VK_ACCESS_TOKEN` + `VK_GROUP_ID` (токен сообщества), затем запустите
  боты-каналы второй командой:

  ```bash
  venv/bin/python run_channels.py
  ```

- **Сайт:** публичная форма на адресе http://127.0.0.1:5000/new — её можно
  давать клиентам или вставить на сайт в скрытый блок (iframe). Для
  программной отправки заявок включите `API_KEY` в `.env` и отправляйте
  POST-запрос:

  ```bash
  curl -X POST http://127.0.0.1:5000/api/new_order \
       -H "X-Api-Key: ВАШ_КЛЮЧ" \
       -H "Content-Type: application/json" \
       -d '{"text": "5 фланцев AISI 321, нужны резка и сверловка"}'
  ```

## Что правится под клиента без программиста

| Что | Где |
|---|---|
| Прайс материалов и стоимость операций, наценка, доставка | `data/price_list.json` |
| Шапка КП: название компании, контакты, срок действия | `data/settings.json` |
| Внешний вид коммерческого предложения | открыть `data/templates/kp_template.docx` в Word и поменять оформление |

## Прайс-лист и бухгалтерия

Прайс правятся со страницы «💰 Прайс», которая есть в шапке системы.
Сначала система работает **без паролей (режим MVP)**: один открытый
интерфейс, прайс доступен всем — заказчику не придётся разбираться со
входом. Если позже заказчик захочет разделить руководителя и сотрудников,
достаточно вписать два пароля в `.env` (ADMIN_PASSWORD, STAFF_PASSWORD и
число компьютеров STAFF_SEATS): появится экран входа, у руководителя —
прайс, у сотрудников — нет. Код менять не нужно.

На странице прайса можно менять цены руками, а можно **загрузить прайс
из Excel** — выгрузку из бухгалтерии заказчика (1С, МойСклад и других):

1. Руководитель выгружает прайс из своей бухгалтерии в файл Excel (.xlsx).
2. На странице прайса выбирает файл и нажимает «Проверить файл».
3. Система сама находит в таблице материалы, работы, наценку и доставку и
   показывает полный список изменений: что появится, что изменится, что
   уберётся — с ценами «было → станет».
4. После нажатия «Применить этот прайс» новые цены идут в расчёты.

До подтверждения действующий прайс не меняется; если файл непонятный,
система говорит об этом и ничего не трогает.

## Окончание сделки: экран КП

Основной документ КП — Word. Таблица позиций автоматически готовится рядом
в Excel. После расчёта кнопка «Коммерческое предложение» открывает готовый
документ: текст КП целиком и таблицу. С этого экрана:

- **Word** и **Excel** — скачивание файлов КП;
- **Отправить** — письмо с тем же текстом, адресом и автоматически
  приложенными файлами Word и Excel. Работает сразу в двух видах: если в
  `.env` задан ящик (SMTP_HOST, SMTP_PORT, SMTP_USER, SMTP_PASSWORD) —
  письмо уходит само; если нет — готовое письмо открывается в почтовой
  программе оператора и файлы прикладываются к нему вручную;
- **Распечатать** — печать полного документа: шапка, текст, таблица,
  итоги (кнопки интерфейса на бумагу не попадают);
- **Отправить в Telegram / ВКонтакте** — файлы Word и Excel уходят ботом
  в переписку, из которой пришла заявка (нужны запущенные
  `run_channels.py` и токены в `.env`).

Важно: Telegram не позволяет писать первыми. Отправка в Telegram и VK
работает по заявкам, которые пришли из переписки там же; для остальных
каналов используйте почту или реквизиты в карточке «Заказчик».

## Структура проекта

```
app.py              веб-приложение: страницы и шаги обработки
run_channels.py     каналы-боты Telegram и VK (второй запуск)
src/
  channels.py       единый конвейер приёма заявок из всех каналов
  telegram_bot.py   канал Telegram (долгий опрос, без сервера)
  vk_bot.py         канал VK (Long Poll сообщества)
  email_in.py       канал почты (IMAP)
  config.py         пути, режимы, чтение .env
  parsers.py        чтение файлов заявок (PDF, Excel, Word, текст)
  recognizer.py     распознавание через ИИ + демо-режим
  pricing.py        расчёт стоимости строго по формулам и прайсу
  render_kp.py      сборка КП в Word по редактируемому шаблону
  kp_text.py        текстовая версия КП (экран, почта, чаты)
  excel_out.py      выгрузка таблицы КП в Excel
  price_import.py   загрузка прайса из Excel-выгрузки бухгалтерии
  mailer.py         отправка писем с КП (SMTP)
  settings.py       данные компании для шапки КП
  db.py             база заявок, права входа и история
templates/          страницы (главная, проверка, результат, прайс, форма сайта)
static/style.css    оформление
data/               прайс, настройки, шаблон, база, файлы (создаётся сама)
demo/               пример заявки для пробного прогона
```

## Этапы развития

- Этап 1 (готов): MVP — загрузка, распознавание, проверка, расчёт, КП в Word,
  история, каналы: файлы, почта, сайт-форма, API сайта, Telegram, VK.
- Этап 2: правка прайса и настроек из интерфейса, PDF-версия КП одной кнопкой,
  выгрузка спецификации для производства, вход по паролю для сотрудников.
